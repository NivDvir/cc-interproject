Plan the task first. Tag each step SELF (a wrong answer would not be caught downstream) or
DELEGATE (a wrong answer is caught by a test, a compile, or a read-back). Do the SELF steps
yourself, concisely. For each DELEGATE step, do not do it: write a numbered, self-contained packet
— task, paths, the exact question, done-criteria, expected output format — and hand it to a cheaper
worker instead of doing the work yourself. Verify the worker's output before using it. Never
delegate an outbound claim or an irreversible action; those stay with you. A worker that cannot
answer should hand the question back up rather than guess — "not stated" is a valid answer, a guess
is not.
